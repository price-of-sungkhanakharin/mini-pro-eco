# Subsystem JSON Log Files (`logs/`)

The `logs` directory contains structured JSON system log files generated by the application components and custom loggers.

---

## 📄 Subsystem Log Files

| File Name | Subsystem Scope | Purpose |
| :--- | :--- | :--- |
| `app.log` | General Application | High-level system lifecycle events and user actions. |
| `backend.log` | FastAPI Gateway | Detailed HTTP requests, response status codes, and endpoint execution timing. |
| `database.log` | PostgreSQL Database | Database query timing, session events, and connection pool status. |
| `minio.log` | Object Storage | S3 storage bucket initialization, object uploads, and download presigned links. |
| `*.log.sample` | Schema Reference | Reference sample files illustrating expected JSON log structure. |

---

## 📊 Structured JSON Log Format Example

```json
{
  "timestamp": "2026-08-14T12:00:00+07:00",
  "level": "INFO",
  "message": "POST /api/v1/auth/login HTTP/1.1 200 - 15ms",
  "path": "/api/v1/auth/login",
  "method": "POST",
  "status_code": 200,
  "client_ip": "127.0.0.1",
  "duration_ms": 15,
  "operation": "POST /api/v1/auth/login",
  "status": "SUCCESS"
}
```
