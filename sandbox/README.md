# Sandbox & Experimental Workspace (`sandbox/`)

The `sandbox` directory serves as an isolated playground for experimental scripts, quick proof-of-concept tasks, and diagnostic verification tools.

---

## 📁 Folder Contents

- **`sandbox/minio/`**: Experimental scripts for testing bucket operations, presigned links, and versioning.
- **`sandbox/test_logger.py`**: Quick script to verify structured JSON log entries before integrating into routers.

---

> [!NOTE]
> Code within the `sandbox/` directory is intended for development spikes and experimentation. Production backend logic resides strictly in `backend/app/`.
